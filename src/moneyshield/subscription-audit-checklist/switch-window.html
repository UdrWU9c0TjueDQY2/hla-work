Which dates should I enter?

Use the last day you can actually use the old service and the first day you can use the new one. If the provider gives an exact expiry time, check that time and time zone separately. This worksheet counts inclusive calendar days and assumes the old service is active by the first overlap day.

Write down the old provider’s renewal status before changing anything. An access overlap is not proof of an extra charge. Trials, credits and prorating can change what you pay.
